# Effective-rank high -> W selector

正式标签：

```text
EFFECTIVE_RANK_HIGH_W@R20261116
```

父策略：

```text
W13612-A015-MOMBIN-3OF5-VOTEONLY-ETF-BC50-BOND30-R20261116
```

状态：`FROZEN_EXPLORATORY_SHADOW_ONLY`。这是已查看历史的探索性研究成果，
不是独立 OOS，不修改生产策略，也不构成未来收益保证。

## 策略逻辑

每月末计算18个申万二级科技行业过去63个交易日的收益协方差矩阵。设特征值为
`λ_i`、权重为 `p_i = λ_i / Σλ`，有效秩为：

```text
ER = exp(-Σ p_i * log(p_i))
```

规则：

```text
若 ER 高于其过去252日滚动中位数：下一月持有新版 W
若 ER 不高于过去252日滚动中位数：下一月持有新版 V2
```

至少需要126个历史状态样本。月末决策，下一月生效；每次在新版 W 与新版 V2
之间切换，额外计10bp单边成本。

## Text 流程图

```text
        |

        |

        |

        |
        +---- 不高 ---------------> 下月持有新版 V2
        |
        v
发生策略切换时扣10bp
        |
        v
计算组合净值、Sharpe、MDD、Calmar
```

## 数据口径

- 数据版本：2026-11-16；
- 最新完整月末评分：2026-10-30；
- 新版 W 使用因果 MOMBIN 和刷新后的77选30 ETF映射；
- 新版 V2 使用同一刷新后的ETF映射；
- 两条基础腿已经包含各自5bp内部成本；
- 选择器切换额外10bp；
- 年化按250个交易日；
- Sharpe为 `CAGR / 年化波动`，现金收益按0。

## 新版基准下的绩效

### 2019-08 至 2026-11-16

| 策略 | 年化 | Sharpe | MDD | Calmar |
|---|---:|---:|---:|---:|
| 新版 W | 63.43% | 2.228 | -29.05% | 2.183 |
| 新版 V2 | 50.14% | 1.633 | -24.53% | 2.044 |
| **EFFECTIVE_RANK_HIGH_W** | **65.44%** | **2.282** | **-26.15%** | **2.503** |

四指标均超过同一新版 W 基准。

但 Sharpe 增量只有约 `+0.054`，63日循环块、5000路径 bootstrap 的95%区间为：

```text
[-0.278, +0.535]
```

区间跨零，因此是历史点估计超越，不是统计确认超越。

## 运行

本目录包含重算所需的最小冻结输入快照，脚本不依赖原项目绝对路径。

```bash

```
